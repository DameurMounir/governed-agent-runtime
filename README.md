# Governed Agent Runtime

**Governed orchestration runtime for evidence-bound multi-agent workflows.**

This is the minimal, review-safe repository bootstrap. The complete `v0.1.0` foundation—
including the professional README, architecture diagrams, roadmap, verification contract,
source, tests, examples, governance, security material, and GitHub templates—is staged on:

[`migration/01-foundation-import-v0-1-0`](https://github.com/DameurMounir/governed-agent-runtime/tree/migration/01-foundation-import-v0-1-0)

The migration is intentionally reviewed through a draft pull request before `main` receives
the implementation. Nothing in this bootstrap claims deployment or production readiness.
