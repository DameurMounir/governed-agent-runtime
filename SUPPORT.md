# Support

## Questions and usage help

Use GitHub Discussions when enabled, or open a public issue that contains a minimal,
non-sensitive reproduction. Include the Python version, package version, command, expected
terminal decision, observed terminal decision, and sanitized evidence output.

## Defects

Open a bug report for reproducible behavior that contradicts the documented contracts. Do not
include credentials, private workflow data, personal information, or unpublished security
details.

## Security concerns

Follow [SECURITY.md](SECURITY.md). Security reports must not be submitted through a public
issue.

## Scope

The current foundation is a reference runtime. Support does not imply production SLOs,
managed hosting, durable state, or compatibility with integrations that are not listed as
implemented.
